# Portal da Ribeirada — Marisqueira

Website institucional da **Portal da Ribeirada — Marisqueira**, em Odivelas.
Site estático (HTML, CSS e JavaScript), sem dependências de build.

## ✨ Funcionalidades

- **Hero** com apresentação e chamadas para ação
- **Sobre** a casa, com a fachada real do restaurante
- **Especialidades** em destaque
- **Ementa** interativa por categorias (dados reais da ementa oficial)
- **Galeria** com _lightbox_
- **Reservas** — botão para sistema online, telefone, WhatsApp e formulário
- **Contacto** com morada, horário e mapa Google
- **Footer** com redes sociais (Facebook e Instagram)
- Design responsivo (desktop, tablet e mobile) e acessível

## 🎨 Identidade

- Cor principal: azul do logótipo `#0b4b77`, com dourado como acento
- Tipografia: Cormorant Garamond (títulos) + Montserrat (texto)

## 📁 Estrutura

```
index.html          Página principal
css/styles.css      Estilos
js/script.js        Ementa dinâmica, galeria, formulário e interações
assets/             Logótipos, ementa em PDF e imagens
```

## 🚀 Como ver localmente

Basta abrir o `index.html` num browser, ou servir a pasta:

```bash
npx http-server -p 5599
```

## ✅ Por configurar

- Substituir as imagens _placeholder_ (`assets/img/`) por fotografias reais
- Ligar o botão "Reservar online" a um sistema de reservas
- Definir o número de WhatsApp e os links reais das redes sociais
- Confirmar o horário de funcionamento
